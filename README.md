# Skin Disease Detection AI

An AI-based skin disease classification system using Deep Learning and Transfer Learning.

## 📌 Project Overview

This project uses a deep learning model to classify skin disease images into multiple categories. The system takes a skin image as input and predicts the corresponding disease category.

## 🚀 Features

- Skin disease image classification
- Deep Learning based prediction
- Transfer Learning
- Image preprocessing
- Model evaluation
- Confusion matrix visualization
- Simple web application for prediction

## 🛠️ Technologies Used

- Python
- TensorFlow / Keras
- NumPy
- OpenCV
- Matplotlib
- Streamlit
- Scikit-learn
